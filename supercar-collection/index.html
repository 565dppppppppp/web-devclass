About

This is a simple college assignment website about supercars. It shows 4 famous car brands: Ferrari, Lamborghini, Bugatti and McLaren. Every brand has 4 cars, so there are 16 cars in total.

The website is made with plain HTML, CSS and JavaScript. All the brand and car information is stored in JavaScript arrays, so the same HTML code does not need to be written again and again.
